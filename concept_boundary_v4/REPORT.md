# V4：用新干预检验模型的失效范围

2026-11-01 03:19:16（Asia/Shanghai）完成。三轮干预、十次真实模型调用和八条新输入评测全部结束，原始记录已回传。数据与执行审计通过；语义审读发现最终选择字段和文字理由矛盾，下面保留实际执行结果。

本轮建立了可执行的范围猜测与单参数实验流程，得到了一条被新数据直接推翻的失效边界。三个新增数学结构，在各自当轮的两条新输入上都没有超过旧 v3_r1 方程。实验语言生成全部使用第三方 API 请求/返回标签为 gpt-6-luna 的服务；实际权重身份未独立核实。

## 已完成的实现

- 把上轮15条公开轨迹与全部6条旧封存轨迹合为开发数据。旧封存轨迹标明为无噪声模拟值，不再作为未见评测。启动候选为三个旧非线性模型。
- Luna 可以为现有模型提出输入特征阈值，预测整轨迹 NMSE 是否超过 .05；也可以明确给出 no_supported_boundary。该阈值定义的是预测误差事件，不是物理机制切换或分岔。
- 工具搜索只改变反向幅度、恢复间隔或首段持续时间的一对输入。候选区分模式要求预测差异超过预定噪声尺度；范围探测模式要求跨越所声明的阈值。先保存完整预测，再取得新观测。
- 每个模型的误差证据独立编号并绑定归属，状态更新不得引用另一个模型的专属失败。原始回答、预测、观测及独立语义审读分别保存。
- 完整轨迹拟合按相同输入整组留出。每次两个起点，轨迹拟合使用 least_squares 的 max_nfev=35；导数式初始化另有 max_nfev=40。数值雅可比还需要额外求值，这不是总函数调用次数的严格上限。

11项工具检查在本地和实际服务器环境通过。本轮使用服务器CPU及外部语言模型服务，没有运行本地GPU模型，也没有增加固定专家角色或开展人数对照。

## 三轮真实反馈

| 轮次 | 新提案 | 实际单参数干预 | 新提案两条事前预测的事后 NMSE | 同轮旧 v3_r1 的 NMSE |
|---|---|---|---|---|
| 0 | 增加第二个线性历史滤波状态 | 首脉冲 +1.5；反向幅度 0.2 / 0.6 | .010904 / .079401 | .005663 / .040937 |
| 1 | 增加输入与历史状态交互 u·z | 首脉冲 -1.5；间隔 0 / 1秒，再 +1.5 | .363801 / .226067 | .248430 / .158738 |
| 2 | 增加记忆平方项 z² | 首脉冲 +1.2；反向幅度 1.1 / 1.5 | .212510 / .036859 | .151956 / .021822 |

各轮的开发数据和拟合参数不同，表格比较的是同一轮、同一输入下的候选。三对实际输入均满足单参数条件。第一轮新模型的开发分组分数一度最好，却在新实验中更差；Luna 随后把它降为 weakened。第二轮全部五个候选在新输入上均超过 .05，揭示了共同的预测缺口。

前两轮明确没有支持的阈值猜测，不能把空标签计入边界准确率。第三轮为当时参数版本的 b4_r1 提出“max_reversal_jump > 2.5 ⇒ NMSE > .05”。随后实际测试两侧输入：

| 反向跳变幅度 | 提交的误差标签 | 实际 NMSE | 实际标签 |
|---|---|---:|---|
| 2.3 | 不超过 .05 | .201240 | 超过 .05 |
| 2.7 | 超过 .05 | .036593 | 不超过 .05 |

两个标签都反了。对应绝对 RMSE 为 .279359 / .156648，观测方差为 .387804 / .670583，差异不只是归一化分母造成的。但低于 .05 也不代表已经达到测量噪声精度。

第三轮问题选择的是 discriminate 模式；编译器在预测差异评分之外优先跨越已声明边界的候选，最终获得了这组反例。没有把它改称为模型选择了 boundary_probe。三轮均在第一次问题提交后找到合格输入，未发生整份问题退回重写；候选级拒绝与问题级拒绝分开统计。三轮各考察36对候选，分别拒绝12、8、4对。

## 最终选择与八条新输入

最终机器可读字段 selected_id 为 **v3_r1**，实际评分执行的也是它。文字理由却在自我纠正数值比较后又推荐 v3_r2。这是最终决策的不一致，不能解释成一个理由充分、确定可靠的选择。原字段、原文和分数完整保留，没有在看到评测结果后替换候选。

最终相同开发数据上，六个候选的分组 CV NMSE 为：

| 候选 | 最终开发 CV NMSE |
|---|---:|
| v3_r0 | 0.092057 |
| v3_r1 | 0.044377 |
| v3_r2 | 0.041260 |
| b4_r0 | 0.041276 |
| b4_r1 | 0.047459 |

v3_r2 的开发分数略低于 v3_r1；新扩展没有成为开发分数最低的候选。此处全是被用于选择的开发诊断，不能与旧冻结模型随记录携带的上轮 CV 值直接比较。

八条新输入在第一次模型调用前已固定；模型从未收到这些输入的结果。最终提交后，按无噪声模拟轨迹评分：

| 执行对象 | 八条平均 NMSE | 超过 .05 的条数 |
|---|---:|---:|
| 上轮最终模型，冻结旧参数 | .087538 | 4/8 |
| 同一旧方程，在本轮最终数据上重新拟合 | .052017 | 2/8 |

后两行的预测逐点完全一致。平均误差改善来自这次旧方程参数更新的实际结果，不能算作三个新增结构的成果；数据增加同时包含六条旧封存轨迹的转入和六条新干预，未隔离两者的作用。八条中七条比旧冻结参数误差更低，一条更高。

实际选择的八个 NMSE 依次为 **.007353、.130606、.179873、.006167、.014005、.034708、.037213、.006209**。两条仍超过 .1，当前预测缺口尚未解决。本轮评测输入不同于前轮，不能直接比较两轮封存均值。

## 解释与流程中发现的问题

**指标误述。** 第一轮 Luna 把 promoted_v3_sealed_2 称为整轨迹 NMSE 超过 .05，实际约 .00991。两条主要失败的确存在，但这条额外陈述错误。局部峰值误差片段和整轨迹 NMSE 是不同量，引用编号有效不保证文字正确。第二轮评述中“预测 NMSE 远低于实际表现所提示的误差水平”也不是可据以解释的数值比较：该字段本身就是观测后计算的实际误差。

**旧关系没有显式保留下来。** 新增 u·z 项破坏了方程的严格反号对称结构。在两组旧局部镜像输入上，第二轮实验前的 b4_r1 预测的镜像残差 RMS 为 .04608、.03144，观测为 .00777、.00693。本轮上下文提供了逐条分组诊断和误差片段，却没有显式传入上一轮的关系摘要。因此这一退步同时暴露了上下文设计问题，不能全归因于模型。

**范围语法与实验语言不一致。** 第二轮两个等待间隔不同的输入，在提供的七个全局描述量上完全相同。模型能选择改变等待间隔，却不能直接声明等待间隔阈值。对初始21条开发轨迹做事后枚举，较好的旧模型在七种单特征阈值中最少仍错一条；这只检查有限描述空间，不能排除更丰富的历史条件。该枚举没有送入当前运行。

**拟合也有不确定性。** 第一轮实验前，新增第二状态的一个参数接近边界 .05，其中一个初始化停在不稳定轨迹的惩罚平台。优化器 success 标志不能单独当作有效拟合证据；最终采用的是目标值更低的可执行拟合。新的预测失败不能直接证明某种物理记忆机制不存在。

**拟合版本与决策一致性仍需完善。** 第三轮边界评述用了重新拟合后的分组误差 .1917/.0277，原事前预测对应的误差是 .20124/.03659；两者标签相同，但不能互换。另有同一份含中文字段的拟合数据，因两处 JSON 编码方式不同生成了两个哈希前缀：底层数据和模型归属一致，统一版本标识仍需修复。这些问题与最终选择字段/文字矛盾一起保存在语义审读中，没有改写原运行。

具体依据见 [独立语义审读](SEMANTIC_REVIEW.json)、[描述量诊断](BOUNDARY_DESCRIPTOR_DIAGNOSTIC.json)和[三对干预记录](DEVELOPMENT_FINDINGS.md)。这些审读没有注入正在运行的冻结流程。

## 对研究目标的含义

本轮实现的是“声明预测范围—执行干预—得到反例—修订模型状态”的开发流程。它尚未得到可靠的失效边界，也没有确认潜变量的物理含义。全部数据仍来自一个已分析的模拟系统；单次开发过程不能建立新理论创造、跨领域发现或论文新颖性的结论。

下一步优先补齐可执行证据记忆：让新方程明确说明如何保留或修订旧成功，同时让范围语言包含真正被实验改变的时间条件。具体设计见 [下一步建议](NEXT_STEP.md)。这是由本轮失败支持的改进方向，不是增加固定角色数量。
