# V4：失效条件与区分实验

2026-11-01。承接用户“继续”的授权。实验语言生成均使用 gpt-6-luna，不做 agent 人数对照。独立目录 concept_boundary_v4，旧版本原始结果与源码不变。

目标：让模型根据完整轨迹误差提出明确的失效条件，再执行单参数成对干预，检查条件预测与竞争方程的事前预测。单个已分析模拟系统的开发续作，不将模型标签或潜变量名称当作物理发现。

## 冻结协议

- 导入上轮15条公开开发观测，全部6条旧封存干净轨迹转为开发数据并标注 noise_std=0；这6条不再承担未见评测。启动模型为 V3 的三个非线性候选，保留旧最终模型的冻结参数作同输入预测参考。
- 每轮 Luna 给出一份候选方程及一条当前旧模型的失效范围声明。范围用公开输入描述量、比较符和阈值表达，目标事件固定为整条轨迹 NMSE > .05。它是可被新输入检验的模型判断，不是已发现的适用定律。证据不足时允许明确弃权 no_supported_boundary，此时只能选择候选区分问题，不强迫捏造失效范围。
- 三轮，每轮最多一次提案、两次问题提交、一次观测判断；最后选择。包含格式修复在内最多20次请求，每次总生成token上限2048。不自动重试网络错误。
- 实验编译器只读取已提交模型和开发输入。可改变反向幅度、恢复间隔、第一段持续时间三种单一控制参数；相同参数的正负极性为候选，不作为额外模型角色。每轮最多执行一对、总计六条新观测。
- discriminate 模式要求两个候选预测 RMS 差异至少3倍测量差异噪声（3×.005×sqrt(2)）；boundary_probe 模式要求该对输入跨越已声明的范围边界。若有限候选没有满足条件，回传原因让 Luna 重写问题；两次失败则本轮不执行。
- 每次先记录完整预测和范围标签，再执行输入。执行后核对单参数关系、计算各模型的事前 NMSE、范围判断是否命中。范围不命中不能自动证明方程错误的物理原因。
- 拟合继续使用完整轨迹、相同输入整组留出、两个起点、每起点最多35次函数评估。数值失败与结构失败分开记录。
- 模型专属证据绑定 model ID、fit版本、observation ID。每个模型的分组诊断和事前误差分别拥有独立证据编号，状态更新不得借用其他模型的专属证据。
- 在任何模型调用前冻结8条新输入和旧最终模型的事前预测。最终提交后统一评估新选择与冻结旧模型，另报旧方程在本轮最终开发数据上重拟合的结果，以区分增加数据/重拟合和更改方程的作用；这是数值参考，不是 agent 人数消融。
- 评测输入不进入模型提示；完成后不再据此修订本轮模型。所有请求、回答、条件、预测、观测、失败、耗时和token单独记录并审计。

## 本轮边界

执行的是有界单参数实验设计；未实现在线闭环控制、外部文献检索或新系统验证。新输入仍属于同一已分析系统。下一轮若使用此次评测误差，需再次将其明确降为开发证据。
