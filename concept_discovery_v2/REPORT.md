# 能生成新状态变量的 agent：首次运行记录

2026-10-31 23:24:44（Asia/Shanghai）完成。**从固定候选表选择，推进到了由 Luna 写出新变量和公式、设计输入、执行预测并修订解释。尚未发现新的科学理论，也未可靠识别这个模拟系统的真实机制。**

按用户要求直接实现，没有开展单 agent / 多 agent 人数对照。所有九次研究生成均请求并返回 gpt-6-luna，通过用户指定第三方 API；实际权重身份无法独立核验。当前聊天模型设置与这些 API 调用分开。

## 做出了什么

原版预写 11 个完整表征，本版初始只有一个当前状态线性模型。Luna 可自行构造导数表达式，定义最多两个潜在状态以及其演化关系。工具只拟合提交的公式，不再穷举旧候选表。数学语言、状态数、参数范围仍受约束。

研究分支挂在具体观测冲突上：在当前状态和输入近似相同的位置，局部变化率却不同。工具先扣除线性模型可解释的小幅状态差异，再给出冲突线索。这是有噪声的近似匹配，不证明一定存在隐藏变量。第一轮一个分支，后两轮各两个分支；同轮分支互不读取对方当轮提案，但共享此前的观测和假说。

分支生成解释后，共享的 Luna 实验设计调用给出两条自定义分段输入。所有当前假说先保存定量预测，工具随后才获取新观测。下一轮看到实际误差与状态匹配结果。全部过程保存在带父节点、目标证据和干预记录的假说图谱中。

## Luna 实际提出的内容

| 轮次与编号 | 概念及可执行定义 | 实际变化 |
|---|---|---|
| 第一轮 r0_b0 | 输入历史：dz/dt = u − p·z | 从当前状态模型新增一个潜在状态 |
| 第二轮 r1_b0 | 同一个输入历史状态 | 重述与复用，没有新增数学结构 |
| 第二轮 r1_b1 | 输出历史：dz/dt = x − p·z | 改为记录过去的输出 |
| 第三轮 r2_b0 | 恢复状态：dz/dt = 1 − abs(u) − p·z | 提出停止输入后的恢复解释 |
| 第三轮 r2_b1 | 输入强度历史：dz/dt = u² − p·z | 提出不区分输入正负的累积量 |

合计五份模型提案、四种不同数学结构。全部由真实 Luna 返回，五份均成功拟合和执行；没有人工代写候选或回退到模拟策略。全部候选仍使用 dx/dt = a + b·x + c·u + d·z；尽管语言允许非线性输出关系，本轮没有提出这种扩展。

模型给出的类比来自“线性系统”“自适应控制”“暴露与恢复过程”等领域，属于模型自身知识生成，没有开放文献检索。它们没有形成已证实的跨领域新联系。特别是第一份提案把“输入变化远快于记忆时间尺度”列为类比失效条件，这并不自动意味着一阶滤波关系失效；输出中写了边界，不代表边界正确。

## 实验真的做到了什么

三轮各执行两条新输入，共六条；加上三条初始输入，共九条可见轨迹。每轮都保存了先于观测的数值预测。**三次成对实验都未达到模型自己设定的当前状态匹配条件。**

| 轮次 | 模型试图区分 | 指定时刻两条轨迹的 x | 自定容差 | 是否匹配 |
|---|---|---|---|---|
| 第一轮 | 当前状态 / 输入历史 | 0.647、−0.515 | 0.04 | 否 |
| 第二轮 | 输入历史 / 输出历史 | 0.650、0.751 | 0.04 | 否 |
| 第三轮 | 有符号输入历史 / 输入强度历史 | 0.695、−0.708 | 0.04 | 否 |

第一轮正负脉冲明显没有得到相近状态。第二轮改为两个正输入时序，差距有所缩小，但仍超容差。第三轮再次采用正负脉冲，重复了已暴露的困难。实际输入确实执行了，所声称的控制条件没有实现，不能把观测差异当作成功反证。

还有两点需要保留：同一条正脉冲被三轮重复使用，这些是带独立观测噪声的重复，不是六条完全不同的干预；“目标不同”也不保证所提议的两种线性隐状态模型在允许观测下可识别。

最终 Luna 选择第二轮的输入历史模型 r1_b0，与第一轮 r0_b0 的数学结构相同。完整可见轨迹的留一轨迹诊断 NMSE 为 0.402，初始当前状态模型为 0.723；这是探索过程中的拟合诊断，不是单/多 agent 效果对照，也不构成独立的改进结论。

最终提交后，在六条封存输入上的平均 NMSE 为 **0.092874**，单条分别约 0.0781、0.0265、0.0272、0.0209、0.3832、0.0214，存在明显较差轨迹。此任务和旧版任务、预算不同，不与旧版分数横向比较。最终模型是线性的输入历史解释，未恢复模拟器中的非线性隐藏反馈，不能称为发现了真实机制。

## 对 novelty 的具体判断

“提出者、联想者、评审者”三个角色的组合不是本轮贡献。已实现的机制是：**把旧描述无法区分的观测冲突，连到新增变量、竞争解释和事先提交的干预预测上。** 潜在状态、反例引导修订、符号表达式和主动实验各自已有研究基础；这套组合是否构成独立研究贡献，本轮没有完成最近工作比较，不能先冠以创新。

实际运行给出了更具体的下一处问题：模型能说出“保持哪些量不变，改变哪些历史”，却不能仅靠文字可靠地给出满足这些约束的输入。下一次实现可让每条反证请求先变成数值约束，由工具搜索可行的匹配输入，并将不可行性返回给 agent 修订假说或实验。这只是下一步建议，本轮没有启动该版本。

## 失败、成本与文件

V1 首次回答 JSON 不合法，第二次修复后来源字段层级错误，共两次调用后停止，未运行新增干预。V2 启用 JSON 输出并简化字段层级，从头独立运行。V1 未混入本版得分，原文与费用保留。

| 版本 | API 返回数 | 输入 token | 生成 token | 其中报告推理 token |
|---|---:|---:|---:|---:|
| V1 格式失败 | 2 | 5,837 | 1,411 | 483 |
| V2 完成 | 9 | 64,997 | 5,539 | 1,398 |
| 本轮合计 | 11 | 70,834 | 6,950 | 1,881 |

推理 token 包含在生成中。第三方价格未知，不虚构货币费用。V2 总运行约 86 秒；数值工具使用第二台服务器 CPU，模型推理由 API 服务提供，不加载本地 Qwen。V2 没有格式错误、请求错误或执行失败。初版失败保留，未无限重试。

数学表达式约束、爆炸状态拒绝、新输入预测及避免重复线性轨迹产生伪冲突等五项执行检查通过。所有生成内容绑定、预测时间顺序、哈希、最终提交后封存预测检查通过。V1 的 12 个文件、V2 的 58 个文件分别与远端逐项 SHA256 一致；六份运行源码也与冻结清单一致。本版进程正常结束，初版失败进程也已退出，不启动新的自动跟进。
