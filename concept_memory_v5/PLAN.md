# V5：可执行证据记忆与时间范围

2026-11-01。依据 V4 的 NEXT_STEP.md 推进。原版本源码和结果保持原样。

## 判断与研究问题

三项建议成立：旧成功需要可复算的记录，新解释需要接受旧成功的回归检查，实验条件需要能进入范围语言。V4 已提供直接开发证据：u·z 扩展削弱两组局部镜像；等待间隔在七个描述量中不可区分；拟合版本哈希不一致。优先修复这些问题能使后续研究结论更可检验。

本轮补充两项约束。第一，旧关系保存为局部观测，允许新反例缩小其范围；回归提示不能变成普遍对称性硬约束。第二，工具回放、设计者指定候选的合成验收、真实语言模型实验分开报告。新系统应同时包含保留旧关系和局部关系在新条件下失效两种情形。

## 实现与验收顺序

1. 统一 spec/fit 的 Unicode JSON SHA256；关系绑定原始观测内容、窗口、噪声假设、输入范围、预测来源与拟合版本。回放旧模型在原输入上的关系误差，明确它是事后回算。
2. 用已知噪声的 99% 卡方上界检验局部反号残差。该阈值以独立 Gaussian 测量噪声、确定性复位为前提，每条关系单独检查。每个输入组取一个记录，重复轨迹不虚增独立关系数量；多关系结果不当作多重检验校正后的统计发现。
3. 新候选得到每条关系的回归记录。冲突处理必须引用关系和准确拟合版本，可撤回候选、声明待检验的范围缩小、或提交可执行的区分实验。声明范围缩小本身不能消除原输入上的预测退步；最终选择显式携带仍未解决的冲突。
4. 安全 JSON 表达式支持输入 u、时间 t、滞后、滑动窗口、持续时间和布尔组合。时间算子只读取截至当前索引的历史；整条已知输入计划可在观测前归约为范围标签。不支持未来测量 x 或任意 Python 执行。
5. 完成真实 V4 记录回放及安全/时序/反例单元检查，冻结代码和协议。再执行新生成的多个动力系统验收，包含奇对称系统和仅在强输入下打破对称的系统。预先保存预测，再生成观测；明确使用设计者指定候选。
6. 同一 V5 流程提供真实 Luna 实验入口。每个新系统从独立公开初始数据开始，3 轮提案/冲突处置/实验/评述，最后提交再评测。每个系统最多 20 次调用、每次总生成 2048 token；无凭据时不伪造模型决定。

## 评价与归因

- 工程验收：V4 两组已知退步能否复现；旧观测、版本、预测来源是否绑定；等待时间能否用通用表达式区分；恶意/超深/未来引用是否拒绝。
- 新系统工具验收：保留关系时能否不误报；局部反例出现后能否登记 counterexample 并保留旧局部支持；每个预测是否早于观测。
- 真实 agent：新输入误差、旧关系回归、已执行反例、未解决冲突、格式和数值失败及成本。只执行有原始返回的调用。
- 后续机制归因需要相同信息、候选语言与预算下的“普通上下文 / 结构化记忆 / 结构化记忆+回归反馈”对照。此轮代码与工具验收本身不构成该因果比较。相关工作需进一步对照反例引导合成、主动系统辨识和预测状态表示。

本轮完成界限：交付可复算实现、旧记录回放、新系统工具验收及真实实验入口；真实模型运行以实际凭据和响应记录为准。
