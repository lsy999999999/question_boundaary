# 把“组合推导”变成可以安排的工作

这是面向所有案例的操作模板。组合产生的是候选解释，推导和测量决定它能走多远。

## 一次组合任务的最小输入

```text
目标观测量 Y：定义、单位、采样与误差。
已知模块 A：输入 U，输出 X，关系 X=A(U;参数)，条件 CA，来源 SA。
已知模块 B：输入 Z，输出 Y，关系 Y=B(Z;参数)，条件 CB，来源 SB。
目前缺口：X 与 Z 是否是同一种可测量量？若不是，缺少何种转换？
可用数据与计算：真实列出。
```

## 八种可尝试的连接

| 方式 | 应交付的内容 | 优先检查 |
|---|---|---|
| 串联 A→B | 中间变量的定义、转换及组合后的预测 | X能否作为Z；条件CA和CB能否同时成立 |
| 并联/竞争 | 同一收支中的不同通量或相互竞争机制 | 重复计数、单位和共享资源 |
| 交互 | 零交互基准、最低必要交互项、组合条件预测 | 交互的尺度、机制含义和单因素对照 |
| 反馈 | 有符号路径、完整状态更新、时序或稳定性预测 | 方向依据、时间分辨率与延迟 |
| 隐藏状态 | 潜变量可测代理和“相同输入、不同历史”预测 | 是否只是吸收残差、可识别性 |
| 空间耦合 | 区室/连续场选择、交换项与边界 | 空间数据、通量依据与尺度 |
| 随机/群体混合 | 分布而非只有均值的预测 | 群体组成变化与个体动力学能否区分 |
| 尺度约化 | 完整模型到简化模型的近似条件与误差 | 被消去过程是否确实更快/更小 |

## 负责人可直接发出的任务

```text
请用所附知识模块A、B及观测E01构建一个最小组合候选。
方法卡：M14、M15、M23。
交付：
1. A/B的输入输出、单位、时间/空间尺度和成立条件表。
2. 你建议采用的连接及一项关键新增假设；指出最可能不成立之处。
3. 变量、方程、参数、初边值、观测函数；不能定义的项逐项列为缺口。
4. 组合相对A-only和B-only新增的一个可测预测，以及反驳该连接的结果。
5. 一个计算请求或最小补充测量，说明返回什么才足以继续。
现有工具没有完成的计算标记为请求；只引用已提供的合格来源。
```

## 抽象接口示例

假设允许的背景知识给出模块A的关系 `X=aU`，模块B在其适用域给出 `Y=bX/(K+X)`。只有在两个模块的X确实指同一种量、单位一致且前提兼容时，才能代入得到 `Y=abU/(K+aU)`。这一步得到一个饱和响应候选；它本身不证明目标系统满足这些关系。

可安排的后续工作是：检查小U下近似线性和大U下饱和极限，给参数范围，比较未见U的预测，或测X。仅观测Y(U)时，变换 `a→ca, K→cK` 不改变预测，因此a与K无法分别识别；加入中间量X的测量可以帮助消歧。

这个例子是人工构造的代数教学例子，未调用模型、未模拟真实测量、没有性能成绩。它说明“组合”需要同时推进接口检查、推导、识别和测量，而不止把两个概念放进同一段话。
