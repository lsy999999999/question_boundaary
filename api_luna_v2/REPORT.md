# Qwen → Luna：固定任务的模型替换结果

2026-10-31。**模型能力确实影响当前任务的表现，但换成 Luna 后，正确卡片加结构映射仍没有显示稳定的额外预测收益。** 本报告只使用完整的 V2 独立重跑；V1 因 API 总生成预算校验失败而停止，其得分与 V2 分开。

## 实际执行

开发 4 个任务 × 7 种方法 = 28 个结果、80 次真实生成，通过原 V4 门槛。正式 24 个任务 × 7 种方法 = 168 个结果、480 次真实生成，五种 agent 各完成 24 个任务。请求与返回模型名均为 `gpt-6-luna`；通过用户指定第三方 API 调用，实际模型权重无法独立核验。

V4 的科学源码、任务种子、系统/用户提示模板、四份卡片及错配方式、数值工具、解析回退、观测次数、每任务四次生成、接受规则和评测规则均保持原样。第二台原 Python 3.10.17 / NumPy 1.26.4 / SciPy 1.12.0 环境执行数值运算，源码复制后核对 SHA256，原 Qwen 目录未改。两个数值基线的开发/正式共 56 个结果均与旧结果在 1e-12 内一致，动作与表征序列一致。

API 参数为 temperature=0、max_completion_tokens=512，每请求 batch=1，并发上限五条，无自动重试。该上限包括服务报告的推理 token；Qwen 的 512 为生成的新 token，tokenizer 与内部计算也不同，因此本轮固定的是调用次数及显式 token 上限，不能声称计算量相等。API 消息仅包含原科学提示与该任务自身历史，不包含当前聊天的研究结论或隐藏测试数据。

## 正式预测结果

NMSE 越低越好；每格为该方法 24 个任务的中位数。原 Qwen 为已完成的 V4 BF16 结果。

| 方法 | Qwen 中位 NMSE | Luna V2 中位 NMSE | Luna V2 均值 | Qwen → Luna 无效输出/96 |
|---|---:|---:|---:|---:|
| 无卡片 plain | 0.000968 | 0.000497 | 0.000764 | 0 → 0 |
| 正确卡片 retrieval | 0.000913 | 0.000456 | 0.000713 | 0 → 0 |
| 正确卡片+映射 structured | 0.001572 | 0.000547 | 0.000787 | 13 → 0 |
| 错配卡片+映射 shuffled | 0.001254 | 0.000524 | 0.000724 | 14 → 0 |
| 固定实验 no_active | 0.000947 | 0.000425 | 0.001051 | 22 → 0 |

强数值基线 history_cv 中位数 0.000384、均值 0.000837；state_fixed 分别为 0.020494、0.067811。五种 Luna agent 的全部 120 个任务均达到任务平均测试 NMSE <0.1，按原共同规则错误接受为 0；这一粗阈值下原 Qwen 同样全部通过。

structured 中位误差比 Qwen 降低约 65.2%，24 个同任务配对中 19 胜、5 负；配对几何误差比 Luna/Qwen 为 0.440，按机制族与实例分层的描述性 bootstrap 95% 区间为 [0.204, 0.851]。retrieval 为 0.477 [0.245, 0.776]，shuffled 为 0.369 [0.190, 0.641]；plain 为 0.632 [0.298, 1.115]，不能据此宣称每种配置都有清晰优势。全部配对结果保存在 [CROSS_MODEL_eval.json](CROSS_MODEL_eval.json)。

## 卡片是否带来额外收益

在同一 Luna 内，structured/plain 的配对几何误差比为 1.060 [0.970, 1.193]，structured/retrieval 为 1.120 [0.948, 1.358]，structured/shuffled 为 1.108 [0.924, 1.323]；均未显示稳定的结构映射收益。更直接的卡片对照 retrieval/plain 为 0.946 [0.784, 1.070]，也没有清晰区分。

structured 与 shuffled 在 21/24 个任务选择相同最终表征，11/24 个动作序列相同；按 1e-12 得分容差，structured 为 2 胜、8 负、14 平。这不等于证明两组等效，但不支持正确卡片带来稳定收益。错配仅循环置换机制正文，保留 ID 与领域文字，仍有名称先验这个已知混杂，不能据此断言模型完全不使用卡片。

history_cv 的中位数仍最低，但部分 Luna 方法的均值更低，不能把基线概括为所有指标都最好。structured/history_cv 的配对比为 1.069 [0.858, 1.369]；所有 Luna agent 与强数值基线的描述性区间均跨过 1。

## 映射与修订的真实内容

正式 structured 有 66/96 次有效非空引用，shuffled 为 39/96；全部来源 ID 合法。已逐条审读两组全部 48 个最终映射，使用实际提示中所引 ID 下的正文，不以来源名称或隐藏机制标签代替正文。

| 最终映射语义 | structured | shuffled |
|---|---:|---:|
| 与所供正文关系相符 | 15 | 5 |
| 部分相符/遗漏关键条件 | 1 | 0 |
| 依据不足或与正文冲突 | 0 | 3 |
| none | 8 | 16 |

这是单人、非盲的关系对齐审读，**不是目标机制准确率**。正式中间轮次和 no_active 未逐条语义评级；另外审读了全部 32 次开发 structured/shuffled 生成。原始映射、实际卡片及逐项理由见 [正式语义审读](SEMANTIC_REVIEW_EVAL.json) 和 [开发语义审读](SEMANTIC_REVIEW_DEV.json)。

shuffled 的 011d4f166882、178794a8cc52、8f0a53158586 在最终仍引用 storage 来解释累积历史，但该 ID 下正文实际是传输时延；另一方面，1f9bd1bae585、58b038a9dcbc 引用 saturation 解释时钟，e377cde4db95、fb6a837878c3 引用 external_clock 解释存储，都符合这些编号下实际置换后的正文。模型同时表现出正文追踪和名称惯性，不能一概而论。

structured 在 9/24 个任务、14/72 个相邻决策处改变表征。所有 agent 共 458/480 次选择当前工具表中 CV 误差最低的候选，Qwen 为 336/480；这里计入其原始格式错误，但没有把回退伪装成主动选择。Luna 的 65 次表征变化中，57 次变到当前最低 CV 候选。主要改善可由更可靠地使用候选证据解释。

例如 structured 的 7dc2896588f5 从 memory_slow 改为 memory_multiscale，最终理由强调非时钟候选的验证比较；三次预测 MSE 约为 0.000149、0.000154、0.000106，最终独立测试 NMSE 为 0.000106。93d24a230259 则在此前预测误差很低的情况下于最终改选 memory_fast。修订次数不等于成功反证次数。模型提出的匹配当前输入/可见状态后改变历史等条件，没有由专门的匹配状态实验直接执行；最终映射提出的条件也没有后续观测机会。示例顺序见 [REVISION_EXAMPLES.json](REVISION_EXAMPLES.json)。

## 失败、预算与成本

V1 使用旧参数 max_tokens=512，第 492 条请求却报告 541 个生成 token，其中 399 为推理 token。预算保护随即停止该版本，保留全部 493 条返回及 120 个已完成正式结果。V2 改用官方明确定义覆盖可见输出及推理 token 的 max_completion_tokens，所有组从头重跑；没有放宽阈值或补换个别分数。V2 开发最大报告生成量 377、正式最大 450；全部 560 次 finish_reason=stop，超限、截断、格式错误、HTTP/传输错误均为 0。见 [V1 失败记录](../api_luna_v1/FAILURE_REPORT.md)。

| 阶段 | API 返回数 | 输入 token | 生成 token | 其中报告的推理 token |
|---|---:|---:|---:|---:|
| V1（失败版本，保留成本） | 493 | 1,501,553 | 108,872 | 54,195 |
| V2 开发 | 80 | 248,744 | 17,704 | 8,842 |
| V2 正式 | 480 | 1,496,109 | 106,037 | 51,179 |
| 两条接入检查 | 2 | 2,819 | 275 | 141 |
| 合计 | 1,055 | 3,249,225 | 232,888 | 114,357 |

推理 token 已包含在生成 token 中。第三方价格和服务端硬件未核实，不虚构货币成本，也不把 API 客户端记录的 GPU 占用 0 当作模型推理不用显存。V2 正式模型阶段墙钟约 930 秒，累计网络请求耗时约 1,869 秒；包括数值工具、排程与网络，不能直接当作与本地 Qwen 的纯推理速度比较。密钥未写入实验文件、日志或记忆。完整成本见 [TOTAL_API_COST.json](TOTAL_API_COST.json)。

## 记录核对与解释边界

V2 全部请求均与 runner 实际计分的消息、回答及 usage 一一对应，560 个响应 ID 唯一，模型名一致。预测先于新观测落盘，预测哈希、最终提交后评测审计错误均为 0；各 agent 均为 6 次观测、4 次生成。原始 Qwen 科学源码未改变。远端 5,345 个文件逐项回传核对通过，SHA256 汇总为 b8ac0436e0c27d3662158bb0a524b59e22fdfe7a76ed38830487132c10af9ed3。失败 V1 的 4,844 个远端原始文件也已逐项核对。

本轮是此前已使用的 V4 固定任务上的模型替换复现，只有一次完整 Luna V2 运行，没有新增未见任务或对同一模型的独立重复；任务依赖、第三方模型身份、不同 tokenizer/推理预算和 API 运行差异均限制因果归因。结果支持模型能力是现有系统的一个瓶颈，不能据此把全部改善归因于某种内部推理机制。

更关键的是，模型仍从预写的 11 种表征中选择，工具已经提供全候选拟合和验证表。当前结果衡量受约束的预测模型选择与修订。它既没有证明跨域映射带来稳定收益，也不能作为 AI 创造新科学理论的证据。要检验用户更广的理论发现目标，需要让模型提出当前候选表中不存在的可执行假说，并用独立预测和竞争解释来检验；本轮没有启动这种新任务。
