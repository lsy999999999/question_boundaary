# 结果解释规则

在正式模型评测完成前固定以下描述性分析，不用于修改任务、模型提示或门槛。

- 按方法对原 Qwen V4 与当前 Luna 作同任务配对，报告全部失败、NMSE 中位数/均值及按机制族和实例分层 bootstrap 的配对几何比值。正式任务此前已使用，结果属于复现性模型比较。
- 比较正确卡片 structured、普通卡片 retrieval、无卡片 plain、错配 shuffled 和固定实验 no_active，保留强数值基线。
- 统计选择当前提示中最小交叉验证误差候选的频率，以及表征变化是否跟随数值排序变化。格式错误单独统计，不把回退当成模型主动推理。
- 检查卡片组之间最终表征、动作顺序及独立预测得分是否相同。根据实际提供在所引 ID 下的卡片正文审读 structured/shuffled 全部最终映射；合法 ID 不等于语义正确。报告单人非盲审读的范围，不把它当作目标机制验证。
- 对表征修订给出实际时间顺序、之前的数值预测误差及最终独立预测。模型提出的反证条件不等于已经执行了对应的匹配状态实验；最终条件没有后续执行机会。
- 网络调用数、失败数、finish_reason、token usage、推理 token 和时间分别汇总。API 服务端硬件及实际价格未核实，不以远端显存 0 或本地内存代替推理资源成本。
- 不从更低的受约束预测误差推出开放式跨域创造力；若模型主要遵循已提供的候选排序，应明确说明。
