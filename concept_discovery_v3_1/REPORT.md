# 从观测失败到模型修订：本轮结果

2026-11-01，Asia/Shanghai。V3.1 三轮真实实验已完成，V3.2 的独立证据复核已完成。所有实验语言生成均请求并收到 `gpt-6-luna` 标签，由用户指定的第三方服务提供；权重身份和货币单价未独立核实。

本轮跑通了“提出数学解释 → 编译可执行实验 → 提交预测 → 获取新观测 → 修订解释”的闭环。新观测支持两个具体判断：在所测正负脉冲下，输出近似镜像；输入幅度增至 1.5 倍时，输出不按 1.5 倍变化。模型据此保留奇对称结构，并尝试更灵活的非线性项。最后选中了第二轮模型，而非最新、最复杂的模型。

## 实际完成的流程

1. 从旧版本九条公开观测和已有候选启动；不向语言模型提供隐藏方程、参数或旧封存轨迹。
2. 数值工具按完整观测轨迹拟合。相同数值输入的重复试验一起留出，避免重复输入泄漏进验证组。每次拟合两个起点，每起点最多 35 次函数评估，输出系数范围为 [-8,8]。
3. 合并重复数学结构；为仿射系统计算包含偏置、零初始状态的精确有理传递签名。实际合并了旧重复提案 r1_b0/r0_b0；本轮没有新增的仿射等价合并。非线性等价没有被自动证明。
4. 将当前最低分模型的分组留出误差交给 Luna，生成新方程和实验问题。工具支持反号、幅度缩放、同状态不同历史三类问题，在有限候选中检查执行条件及预测差异。
5. 保存事前预测，再执行模拟器输入，计算实际关系和预测误差，交给 Luna 更新解释状态。
6. 三轮结束后提交最终模型，再评估六条预先固定、此前未提供的新输入。

代码、请求、原文、预测、观测和最终提交均保留。按用户要求，没有开展单/多 agent 人数对照。计算使用第二台服务器的 CPU 数值环境和外部模型 API，没有运行本地 Qwen，也没有占用该机 GPU 推理。

## 三轮发生了什么

| 轮次 | 模型修订 | 实际实验 | 新证据 |
|---|---|---|---|
| 0 | 去掉常数项，保留衰减输入记忆和 x、x³、u、z 项 | ±1.2 脉冲，0.5–4.5 秒 | 镜像关系偏差 RMS 0.00777，噪声预期 0.00707；但新模型两条预测 NMSE 仍为 0.09354、0.09186 |
| 1 | 增加 tanh(x)，容纳幅度相关的残差 | ±1.2 脉冲，0.5–3.5 秒 | 镜像偏差 0.00693；新模型两条预测 NMSE 为 0.00533、0.00511，前一模型为 0.01895、0.01880 |
| 2 | 再增加 x·tanh²(x) 修正项 | 0.9 与 1.35 脉冲，0.5–4.5 秒 | 比例关系偏差 RMS 0.25963，噪声预期 0.00901，显示这些输入下的非比例响应 |

这里 x·tanh²(x) 整体并非有界函数，只有其乘法因子趋于饱和。正负镜像是局部试验结果，不能推广为任意状态、任意输入下的定律。

第三轮新模型 v3_r2 在该对新输入上的事前预测确实更好：NMSE 为 0.00340、0.00718，v3_r1 为 0.00347、0.01083。最终仍选择 v3_r1，依据是全部开发数据的分组留出表现，而非第三轮新模型输掉了这对试验。原最终回答低估了已有的完整预测比较信息；这里按原始数值纠正叙述，原回答保留。

## 预测结果

全部候选在最终相同开发数据上的分组留出 NMSE（越小越好）：

| 候选 | NMSE |
|---|---:|
| 初始模型 initial | 0.788351 |
| 旧输入记忆模型 r0_b0 | 0.526759 |
| 旧输出记忆模型 r1_b1 | 0.697038 |
| 第一轮 v3_r0 | 0.052820 |
| **第二轮 v3_r1，最终选定** | **0.007810** |
| 第三轮 v3_r2 | 0.012378 |

这些是被反复用于提案和选择的开发分数，不能当作独立确认或模块因果效应。拟合得到的最终关系为：

```text
dz/dt = u − 0.728360 z
dx/dt = −0.734443 x + 0.042046 x³ + 0.818837 tanh(x)
        + 0.849510 u − 0.336100 z
z(0) = 0
```

最终全数据拟合的两个优化起点均收敛；z 仍是预测用潜变量，其物理含义未被确认。

六条新封存输入的 NMSE 依次为 **0.00861、0.01152、0.01445、0.13608、0.10557、0.00867**，平均 **0.04748**。其中两条误差超过 0.1，表明跨输入预测仍有明显缺口。这六条输入来自已经分析过的同一模拟系统，并非六个新系统；其输入也不同于 V2，不能把两版封存均值直接当作同条件提升。

## 实验门控实际发挥了什么作用

三轮各搜索 16 个候选，分别拒绝 0、1、15 个候选，选出的三对输入在执行后均满足对应输入关系条件。本次三个首次提交的问题都找到可执行方案，没有出现整份新问题被退回并由 Luna 重写的情况。

本轮没有执行“同状态不同历史”实验，因此还没有新的实测证据说明状态匹配难题已解决。旧三次失败设计的工程重放和单元检查独立保存。有限搜索未找到方案，只表示在当前候选范围内未找到。

## 失败、审计与修订

**V3 工程失败。** 首版在两次真实生成后，因编译器产生 numpy.float64 时间值被严格输入校验拒绝，尚未执行新增干预。V3.1 在独立目录仅修复时间转换并补充检查，从原始公开种子重新开始。V3 的 22 个原始文件保留，不与完成运行混分。

**V3.1 原始证据归属错误。** 人工审读找到四条状态更新，把当前最佳模型的失败引用到了其他模型：第 0 轮 r0_b0、第 1 轮 v3_r0、第 2 轮 v3_r0 和 v3_r2。部分更新同时引用了有效观测，但不能抵消错误归属。完整记录见 [事后诊断](POSTRUN_SUMMARY.json)。原分数和预测未修改，涉及这些更新的原概念状态不能直接作为可靠科学结论。

**V3.2 修复与单独复核。** 失败证据现在绑定模型 ID、拟合版本及观测 ID，状态更新拒绝跨模型的专属证据引用。七项测试在本地及服务器通过。随后用一次真实 Luna 调用，重新审读六个模型的公开开发证据：三个旧模型标为 weakened，三个新模型保留为 active。六条引用均通过归属检查；active 表示保留候选，“接近”等文字判断仍是定性评价。此次未重新拟合、未新增观测、未提供封存结果，未改变原最终选择。**V3.2 的完整三轮发现流程尚未运行。**

V3.1 的十次返回与决策绑定、预测哈希、预测先于观测、最终提交先于封存评测等审计通过；72 个原始文件回传哈希一致。V3.2 复核的五个原始文件、九份源码和公开输入共 15 个文件与远端一致，原文与保存结论、六个模型的引用归属均核对通过。数值/时序审计与文字语义审读分别记录，前者通过不代表后者自动正确。

## 距离研究目标及下一步

现在已有的能力是：模型可以写出新候选方程、提出可执行输入，并根据实际残差继续修订。当前证据来自一个经过多轮分析的模拟系统；还没有自主跨领域文献检索、在线反馈实验控制、物理潜变量识别或新自然理论发现。论文新颖性也尚未由近邻研究比较确立。

下一步应围绕**解释在哪些条件下失效，以及什么干预能改变这种判断**继续推进。优先处理两条封存输入暴露的外推缺口，将它们转为明确的边界问题；一旦用于开发，它们便不能继续充当未见测试。再在独立新系统上执行冻结后的证据归属版本，检验能否反复完成“定位失败条件—提出区分实验—修订概念适用范围”。这比增加固定角色数量更贴近当前数据揭示的瓶颈。跨领域材料应在明确缺失的机制问题出现时引入，并记录它具体改变了哪个方程或预测。

本次授权的实现与运行已完成，未启动后续批量实验或自动跟进。
