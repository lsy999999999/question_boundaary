# 给科学调查agent配置负责人和方法库

2026-11-02。**已写好leader提示词、研究执行提示词和44张可按缺口调用的方法卡。** 本轮完成文献整理与提示词方案；尚未启动新模型实验或自动编排服务。

首例RNA记录表明agent已经尝试把知识组合起来，主要停在未闭合方程、未执行拟合和未补齐关键机制依赖。当前方案让leader识别具体缺口，再安排检索、组合、推导、计算或测量。负责人按证据推进研究，最终交付预测及认识变化。

## 直接使用的文件

- [Leader系统提示词](LEADER_SYSTEM_PROMPT.md)：诊断缺口、选方法、安排任务、检查交付物。
- [执行agent提示词](RESEARCHER_SYSTEM_PROMPT.md)：交付可审查的知识、模型、计算或预测。
- [44张方法卡](METHOD_LIBRARY.md)与[简短索引](METHOD_INDEX.md)：每张包含何时用、需要什么、怎么做、产物、局限和受阻后的行动。
- [组合推导操作模板](COMPOSITION_PLAYBOOK.md)：八种连接方式、可直接发送的任务及抽象代数示例。
- [装配与运行约定](RUN_PROTOCOL.md)：开场输入、实际工具、预算、信息隔离和证据记录。

## 负责人每轮做什么

```text
现象与当前模型
  → 确认一个主要缺口
  → 取1–3张方法卡
  → 安排一个具体产物
  → 获取真实计算/测量结果
  → 修改模型与认识
  → 选择下一步或封存预测
```

方法覆盖观察构造4项、约束与降维6项、知识迁移4项、机制组合8项、推导计算8项、模型批评与实验6项、修订管理4项、调度交付4项。模型仍可提出库外方法。

不是每轮都需要新增角色；同一个gpt-6-luna可以顺序执行多项工作。leader和执行agent均不接触组织者保存的目标论文答案。本方案优先改善任务选择和交付约定。
