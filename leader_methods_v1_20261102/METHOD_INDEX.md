# 方法索引：44张卡

leader每轮按当前缺口取1–3张完整卡；下列不是必须依次执行的清单。可以提出库外方法。

## A 观察与问题构造

| ID | 方法 | 何时调用 |
|---|---|---|
| M01 | 观测量与潜在状态分开 | 同一个图像或汇总指标可以由不同变化产生。 |
| M02 | 因果图与替代路径 | 条件A/B有差异，但处理同时改变多种因素。 |
| M03 | 把复合现象拆成可分别解释的子问题 | 一句话同时要求解释出现、持续、大小和运动等多个现象。 |
| M04 | 把现象整理成约束集 | 已有多项观察，但假说只解释其中一项。 |
## B 约束、降维与初步推导

| ID | 方法 | 何时调用 |
|---|---|---|
| M05 | 从守恒与收支写方程 | 解释只有作用名称，没有状态如何变化。 |
| M06 | 量纲分析与无量纲组合 | 变量很多，拟议方程单位混乱，或想比较不同尺度。 |
| M07 | 竞争时间尺度与长度尺度 | 稳态直觉解释不了滞后、持续或空间差异。 |
| M08 | 极限、边界和退化情形推导 | 新方程看似合理，但尚无简单一致性检查。 |
| M09 | 对称性、坐标与不变量 | 不同表述可能等价，或关联依赖坐标定义。 |
| M10 | 可分解性与标度折叠 | 高维函数难以推导，但可能由较低维关系组成。 |
## C 知识获取与跨领域迁移

| ID | 方法 | 何时调用 |
|---|---|---|
| M11 | 按缺失知识检索 | 不知道一个过程的成立条件、测量方法或本构关系。 |
| M12 | 按功能或关系寻找外领域知识 | 本领域搜索反复返回同样解释。 |
| M13 | 结构类比映射 | 找到了灵感，但不知道如何用于当前系统。 |
| M14 | 把论文知识提取为可连接模块 | 文献很多，却无法据此建立模型。 |
## D 机制组合与表示修订

| ID | 方法 | 何时调用 |
|---|---|---|
| M15 | 机制图补桥与串联组合 | 分别知道A影响B、C影响D，却解释不了从处理到结果的整条链。 |
| M16 | 并行过程的竞争与耦合收支 | 两个机制可能同时存在，而非非此即彼。 |
| M17 | 交互项与非加性机制 | 两个因素单独影响弱，合并后出现异常响应。 |
| M18 | 反馈与延迟组合 | 现象有振荡、过冲、适应或长时间滞后。 |
| M19 | 隐藏状态、记忆与路径依赖 | 相同当前输入对应不同结果，误差依赖历史。 |
| M20 | 从整体模型扩展到空间模型 | 整体平均解释不了不同位置的差异。 |
| M21 | 异质性、随机性与群体混合 | 均值变化可能来自个体动力学，也可能来自群体组成。 |
| M22 | 尺度约化与有效变量 | 组合模型过大，无法估计或计算。 |
## E 推导、计算与参数

| ID | 方法 | 何时调用 |
|---|---|---|
| M23 | 方程闭合与计算依赖检查 | 出现未定义g/h、成核规则、力或通量，无法实际计算。 |
| M24 | 稳态、局部稳定性与阈值推导 | 需要解释何时出现新状态、何时保持或消失。 |
| M25 | 前向计算与观测预测 | 解释已有公式但还没有可对照数据的数值预测。 |
| M26 | 符号回归与方程骨架搜索 | 变量已知，关系形式未知，且有足够数值样本。 |
| M27 | 稀疏动力学与空间方程识别 | 有足够时间或时空测量，且合理假设动力学在候选库中稀疏。 |
| M28 | 结构与参数分离拟合 | 研究者凭文字选参数，或把优化失败当成结构错误。 |
| M29 | 参数与机制的可识别性 | 不同参数/机制拟合相近，却得出不同解释。 |
| M30 | 敏感度与不确定性传播 | 已有模型，但不知道哪些参数决定结论。 |
## F 模型批评与区分实验

| ID | 方法 | 何时调用 |
|---|---|---|
| M31 | 残差结构与后验预测检查 | 总体误差可接受，但局部条件或分布特征不对。 |
| M32 | 针对反例做最小结构修改 | 已有一次明确失败，但新提案只是换词。 |
| M33 | 选择能区分候选的实验 | 多个模型都解释现有数据。 |
| M34 | 阻断、匹配与因子组合实验 | 几个原因随处理一起变化，或怀疑交互作用。 |
| M35 | 边界探测与外推条件 | 候选在已见范围相近，需要检验其适用域。 |
| M36 | 测量伪影与替代观测模型 | 结论依赖阈值、共享分母、坐标、轨迹长度或筛选规则。 |
## G 修订与证据管理

| ID | 方法 | 何时调用 |
|---|---|---|
| M37 | 把失败变成后续生成约束 | 模型承认失败，下一轮却原样再提。 |
| M38 | 证据强弱、反证与停止 | 证据越来越多，但混入重复信息或反复挑选检验。 |
| M39 | 模型等价、去重与结构差异 | 候选越来越多，但只是变量改名或重参数化。 |
| M40 | 旧证据回归与局部适用范围 | 修订解释了新反例，却破坏旧规律。 |

| ID | 方法 | 何时调用 |
|---|---|---|
