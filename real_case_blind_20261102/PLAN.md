# 真实案例的隔离式发现测试

日期：2026-11-02。目标：从近期真实研究中选择有可获得观测数据的现象，让独立的 gpt-6-luna 研究 agent 在不接触目标论文结论的情况下形成解释、申请证据并提交预测，最后与隐藏结果和论文解释对照。

用户后续明确采用时间截断检索：以目标研究最早公开日期为界，禁止检索当日及之后的信息。首例选用2026-10-07正式发表、2025-05-13首次预印本的RNA液滴研究；背景检索截止2025-05-12。该规则控制本轮检索信息，不能证明模型预训练未见。

## 选题条件

优先检索2026年、截至2026-11-02已公开的物理、材料、化学、生物和行为研究。核对最早预印本日期，而非只看期刊年份。候选需有可验证原始来源、公开数据或可运行的实验/分析，存在可相互区分的解释，且可在现有计算条件下开展测试。只有图像、付费不可读正文、无可获取数据或只能由模型猜想的案例，不视为可执行案例。

## 信息隔离

- curator/：原论文、作者结论、答案、数据划分和评分规则，由组织者使用；不提供给研究agent。
- agent_workspace/：仅放去除题名、作者、DOI和结论的现象描述、初始观测、测量定义、工具说明和允许的背景知识。
- 研究agent使用全新上下文；不继承本聊天、项目记忆或组织者的答案。禁止读取隔离目录、搜索目标论文及其派生报道。文件可见性约束的实际执行强度必须如实报告。
- 若开放文献检索，检索代理先记录查询并检查返回内容；发现目标答案泄漏，相关后续结果不能记作盲发现。
- 记录模型在获得数据前的解释和已知来源，作为识别风险检查；正确说出熟知机制既可能源于既有知识也可能源于推断，不能仅凭问答证明训练集未包含目标。

## 执行与结果

冻结初始材料、逐步开放的原始证据、未见预测数据和评估标准后再调用模型。先承诺预测再开放真实观测；记录解释、预测和修订原因。利用已有数据申请未公开条件属于回放式证据获取；数值分析属于计算实验；不声称运行了新的实体实验。

不能保证黑盒模型的预训练未知性。可保证的范围是本次上下文未直接提供答案，并记录污染检查结果。若案例首次公开早于模型训练边界或训练边界无法核实，明确标为未知。实验不得用设计者重写的目标方程生成数据冒充真实观测。

本目录独立于所有既有V1–V5.1实验；不修改旧结果。不因agent失败而改写隐藏答案或合格门槛。研究生成沿用用户指定gpt-6-luna。
