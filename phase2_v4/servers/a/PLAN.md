# 第二轮：证据驱动的表征修订

授权：2026-10-31 用户要求建立第二台服务器环境并让两台一起运行。

## 问题与本轮改动

首轮 structured 表征集中、没有有效非空卡片引用。本轮检验：向所有 agent 提供相同的候选模型验证与实验预测分歧后，模型能否根据证据修订表征，以及机制卡片内容是否带来额外收益。

候选表征、模拟器、初始实验、观测预算和接受阈值沿用首轮。所有 agent 在每次决策前得到全部 11 个候选模型的训练轨迹交叉验证误差，以及候选模型对可用实验的预测分歧；这些计算只用当前可见训练轨迹。每任务 52 次拟合调用、4 次生成；history_cv 为 51 次拟合、state_fixed 为 7 次。此设计评价“数值工具辅助下的 agent”，独立于首轮弱诊断配置。

## 冻结对照

| 方法 | 数值工具 | 机制卡片 | 显式映射 | 后续实验 |
|---|---|---|---|---|
| state_fixed | 当前状态回归 | 无 | 无 | 固定 |
| history_cv | 全候选验证搜索 | 无 | 无 | 预测分歧 |
| plain | 相同候选证据 | 无 | 无 | 模型选择 |
| retrieval | 相同候选证据 | 正确卡片 | 无 | 模型选择 |
| structured | 相同候选证据 | 正确卡片 | 有 | 模型选择 |
| shuffled | 相同候选证据 | 内容束循环错配，标识和领域保留 | 有 | 模型选择 |
| no_active | 相同候选证据 | 正确卡片 | 有 | 固定 |

允许 source_id=none；不强迫引用。卡片语义、来源枚举有效、非空引用率分别报告。所有无效输出和回退计入结果。预测轨迹先落盘再取新观测；最终模型先提交再评测。

## 任务与门槛

- 开发：4 个机制族 × seed 201；与首轮开发/正式任务分离。
- 正式：8 个机制族 × seeds 31、32、33，24 个任务；总计 168 个正式任务/方法结果，480 次真实生成。正式得分不用于调整当前版本。
- 开发进入正式的预设条件：全部开发任务完成；各 agent 无效输出率不超过 25%；structured 至少一次有效非空卡片引用、至少一个任务发生表征变化；全部预测/提交时序及哈希审计通过。非空引用仅用于确认操作被调用，语义正确仍需审读。若失败则保留开发结果、停止该版本正式运行，记录原因，不把程序回退伪装成模型修订。
- 指标：测试 NMSE（均值、中位数、配对比值及机制族分解）、错误接受、候选表征分布、逐轮修订率、卡片引用与无效率、生成/数值成本。源标识或表征变化本身都不作为新理论发现的证据。
- 模型：同一 Qwen2.5-7B-Instruct，第二台 GPU BF16，greedy、batch=1、每次上限 512 新 token。与首轮 CPU FP32 得分独立保存。

## 分工和资源
