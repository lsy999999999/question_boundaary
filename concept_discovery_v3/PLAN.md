# V3：让观测证据改变行动

2026-11-01。用户已授权按数据复盘实施。本轮在同一已分析系统上做开发续作，不声称新系统泛化，不做单/多 agent 消融。语言生成全部请求并要求返回 gpt-6-luna；实际权重身份仍仅依据第三方声明。

## 冻结范围

- 导入 V2 的九条公开观测以及初始模型、两份重复的输入历史提案和输出历史提案。重复结构合并，原记录保留。没有向 Luna 提供隐藏方程、参数、机制名称或旧封存轨迹。
- 数值工具直接拟合完整轨迹，按相同数值输入分组；每次两起点、每起点最多35次函数迭代，输出系数限制 [-8,8]。独立输入组等权，全部重复一起留出。旧的平滑导数拟合仅作数值初始化，不作选择目标。
- 对仿射系统使用与显式同步 Euler 等价的快速执行器。等价签名使用保存的十进制参数构造有理数传递函数，包含偏置和零初始状态；非线性系统不伪称已证明等价。
- 最多三轮，每轮一次新提案、最多两次实验问题提交、一次观测后判断；最后一次提交。包含格式修复在内硬上限20次 API 请求，每次总生成 token 上限2048，temperature=0，无网络自动重试。
- 实验问题支持正负反号、正幅度缩放、同状态不同历史三种类型。数值工具仅用已提交模型搜索输入；找不到合格方案时把原因返回 Luna。主动区分模式需要预测差异；明确的关系探测模式允许检验多个模型共同的假设。
- 匹配类试验要求各保护模型的预测状态差距 <= 请求容差的一半，并要求目标模型预测斜率效应差>=0.06。保护模型是目标模型及当前最低分模型，非参数不确定性全覆盖。搜索有限，不把未找到解当作不可能性证明。实际条件仍在执行后检查。
- 每轮只针对当前最低分非退役模型的分组留出失败及已有关系证据提案；不继续调度过时的 x/u-only 碰撞。概念状态由 Luna 根据实际证据更新，记录为模型判断而非自动科学认证。
- 最多六次新观测；最终选定模型后执行六条预先固定的新输入。仍属于已分析系统的开发结果。下一阶段未见系统评测尚未启动。

## 记录与边界

所有模型原文、重复合并、求解退回、预测承诺、实际条件、关系诊断、概念状态变化以及失败均落盘。历史三次坏设计的拦截检查单独标为工程重放，不冒充本轮新实验。

不会强迫模型制造一次失败或宣布概念突破。若三轮内没有可靠概念修订、实验全部被退回或模型不充分，则如实交付。外部文献检索、泛化的实验语言和在线反馈控制尚未实现；本版执行的是有界离线输入设计及执行后的条件检查。
