# 下一版建议：让证据改变概念与实验

状态：依据 2026-11-01 数据复盘提出，尚未开始新版本实验。所有研究语言生成继续使用 gpt-6-luna；不做单/多 agent 人数对照，也不增加固定专家角色。已查看的旧任务数据属于开发证据。

## 目标

完成一条可追踪的发现过程：当前解释在哪里失败 → 一项明确的竞争判断 → 可执行的区分实验 → 实际观测是否满足条件 → 合并解释、修改关系、增加变量或缩小适用范围。

新增变量的数量、agent 的数量、讨论轮数都不作为成果指标。一次明确说明原因的“这两种概念不能由现有观测区分，因此合并”也属于进展。

## 第一优先：把实验意图交给工具实现

Luna 输出实验问题，而不是只写两条猜测性的波形。问题字段至少包括：

- 要区分的假说或约束；其差异必须指向可观测量。
- 实验类型：同状态不同历史、输入反号、幅度缩放、时间顺序改变，或由模型提出的其他可计算性质。
- 需要控制的量、比较区间、容差和测量噪声。
- 结果怎样改变具体判断；无法满足前提时该结论不成立。

工具在有界输入空间搜索，返回条件可行性、各模型的预测、预期差异与噪声尺度。多模型都不满足约束，或预测差异小于可分辨程度时，退回模型修订问题；不得以一句 failure_of_design 代替处理。

求解器只能使用公开数据和已提交候选，不能读取隐藏模拟器。模型内可行性不是实际保证：执行时要观察匹配是否成功；必要时以观测反馈控制进入目标状态，并说明控制可能改变隐藏历史。必须区分实验条件不成立、预测被反驳和数据暂不足这三种结果。一次实验的次要信息仍可进入证据记录。

## 第二优先：维护概念的证据状态

对每份新假说记录：

- 与已有表达式完全重复、可证明观测等价、在已有证据下未区分、或提出新的可检验预测。
- 对线性隐状态模型比较输入输出传递关系和偏置响应；不要把隐藏坐标命名当成新机制。非线性模型的数值近似不等价于数学等价证明。
- 每条旧反例在当前模型下还剩多少解释缺口。局部拟合诊断、事前预测失败和真正新观测分别标记。
- 类比引入了什么可计算关系，哪些对应只是语言描述，已有数据支持哪些部分，何时应放弃或缩小范围。

待研究问题按当前模型的未解释预测排列，避免重复的观测编号和重复模型消耗分支。分支可提议修改已有关系、合并概念或提出更有用的测量，不必每轮增加隐状态。

## 第三优先：提供可靠的数值证据

- 对同一数值输入的所有重复一起分组，重复观测用于估计噪声，不伪装成新输入泛化。
- 尝试积分式/轨迹式拟合及有限多起点；同时报告执行稳定性和拟合不确定性。先在独立小例子上检查数值工具，不能把失效的拟合器交给 agent 当裁判。
- 把整体分数拆为具体时间段、输入类型和结构性质的误差。检查短脉冲在拟合器中是否还有足够有效样本。
- 不用已看过的隐藏方程设计正确候选。若继续当前模拟系统，只称开发案例；后续独立运行必须使用新封存任务。

## 第一条新的科学问题

现有数据支持某一种脉冲下的近似正负镜像。让 Luna 据此组织下一问：改变幅度、持续时间或历史顺序后，镜像关系是否保留，幅度比例关系是否改变？根据实际差异决定是修改响应关系还是增加状态。

匹配实验只在它确实能回答当前争议时使用。若两个“记忆”解释只是坐标变换，应合并并追踪共同失败；不继续设计不可能证明语义不同的实验。

## 完成标准和交付

一条有明确证据变化的闭环运行即可作为下一次原型交付，不做 agent 数量消融，不为得到正面结果无限扩展运行。至少展示：不合格设计被退回的实际记录、一个得到信息的实验及其有效前提、一个有原因的概念状态变化，以及剩余无法区分的问题。失败同样完整保留。

研究 novelty 的候选落点是“由干预可区分性约束的概念合并、修订和扩展”，不是常见角色分工。预测状态表示、系统辨识和反例引导合成等既有方向必须在后续定位中正面对照；本计划不声称这些基本构件是新的。
