# RNA V2 frozen protocol

2026-11-02. One gpt-6-luna leader and one gpt-6-luna general executor, independent fresh role contexts per run. No standing retrieval role. Curator operates deterministic retrieval/computation broker, never supplies scientific relations or parameter choices. All actor inputs, outputs, raw retrieval responses, submitted code, stdout, stderr and immutable state versions are retained. This is application-level allowlisting, not OS isolation or proof against model pretraining.

Stage A has zero model calls: test a historical background search and an existing public C04 partition computation, state return to both roles, error and clarification transitions, frozen hash verification and disallowed input rejection. Fixtures do not count as agent discovery.

Stage B: six independent reconstructed continuations (A1/A2 free scheduling; B1/B2 proactive relation retrieval; C1/C2 product acceptance). All share byte-identical visible materials, tools, method library and deliverable schema. Only the scheduling paragraph differs. Each run at most 3 leader and 3 executor replies, 3 searches, 3 calculations. Common order L1 R1 [tools] L2 R2 [tools] R3 [tools] L3 final adjudication. Model sampling is tool default; requested model is fixed, actual backend and token/billing totals may be unavailable. No model reviewers or implicit retries: total B <=36, C <=12 replies, retries/reviews consume these same caps. No precise original-context replay claim. The complete V1 input log was unavailable, so visible round-1-to-4 materials and original replies are reconstructed without rounds 5/6, later fits or withheld observations. Candidate checks are within the two roles' budget; curator review is nonblind, takes place after freeze, and is not fed back.

Stage C only proceeds after B produces a calculable candidate passing substantive checks. Choose B when equally useful and cheaper; choose C if only C succeeds. Freeze choice before starting; fresh roles see initial case, not B scientific outputs. At most 12 replies, 6 searches, 10 calculations. Reserve executor check and leader final responses. Stop early on repeated unrepaired scientific failure or resources unavailable.

Each main task points to candidate_id and gap_id. Separate mechanism and auxiliary_fit tasks. Allowed transitions: todo -> executing -> waiting_tool/clarification -> acceptance -> completed/rework/blocked/stopped. A tool result only moves a task to acceptance. Completing a fit never closes a mechanism gap. Mechanism completion requires explicit marked assumption, closed defined relation, calculation/derivation artifact, observation mapping, a discriminating conditional prediction, basic checks and leader adjudication. Formal completeness only gates submission; semantic validity is separately reviewed.

Missing data may lead to explicit conditional hypotheses, reduction, parameter ranges and limiting cases. Unknowns are not facts. A single arbitrary parameter illustration is not parameter inference. No numerical error band is called a confidence interval without a noise/replication model. Image statistic is arithmetic mean per-droplet 2D area fraction; concentration, volume and population-average conversions require an observation model.

Retrieval uses executor's missing_relation, variables, conditions, query, change_if_found. Europe PMC core abstract search with first publication <=2025-05-12, deterministic result order and target DOI/family exclusion. Return raw abstract sentences, date/DOI and explicit abstract-only scope; no curator scientific summary. Executor supplies variables/conditions, supported relation and adoption/modification/rejection after seeing results. Historical eligibility is metadata-based, not a cryptographically archived abstract version; records with unknown dates or target-derived content are quarantined. Endpoint coverage/no hits/failed retrieval are recorded. Additional refinement counts as a query.

Compute executes executor-authored Python in a dedicated working directory with only explicitly opened measurements copied there, timeout 30s, output cap, unmodified code hash. Broker rejects obvious file/network/process operations, but this is not a security sandbox. It does not invent a scientific model, parameters or boundary conditions. Missing specs return clarification; failures retain stderr. Derivation/code/result linked by ID. Frozen submission hashes include every public artifact and ledger; later edits invalidate verification. Hidden evaluation is a separate post-freeze process and never part of actor inputs.

Primary evaluation: incremental relation, valid derivation/computation, compatibility with available evidence, measurement mapping and distinction from a meaningful alternative. Published mechanism comparison is separate. No wet-lab trial or independent confirmation is implied. Six runs locate development bottlenecks, not stable improvement or significance. Full costs include every spawn/followup, tools, failures and human implementation/audit; no credentials stored.
